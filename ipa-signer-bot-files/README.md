# 📱 iOS IPA Signer Telegram Bot

एक संपूर्ण और शक्तिशाली Telegram Bot जो iOS IPA फाइल्स को साइन (Sign) करके देता है।

---

## 📸 Bot Interface (अपडेटेड मेनू लेआउट)

सामान्य यूज़र्स के लिए मेनू:
```text
┌───────────────────────┬────────────────────────┐
│     📲 Sign IPA       │   📦 My Certificate    │
├───────────────────────┼────────────────────────┤
│     🔍 Check P12      │   🖼️ Change Thumbnail  │
├───────────────────────┴────────────────────────┤
│                  ⚙️ Settings                   │
└────────────────────────────────────────────────┘
```

एडमिन (**@YQIS**) के लिए अतिरिक्त बटन:
```text
┌───────────────────────┬────────────────────────┐
│     ⚙️ Settings       │   👑 Admin Dashboard   │
└───────────────────────┴────────────────────────┘
```

---

## 🚀 मुख्य अपडेट्स और विशेषताएं (Features)

1. **⭐ VIP हटा दिया गया (100% Unlimited for Everyone):**
   - सभी यूज़र्स के लिए साइनिंग पूरी तरह मुफ़्त और असीमित (Unlimited) है। कोई लिमिटेशन या VIP रुकावट नहीं है।

2. **📁 2GB से ज्यादा (>2GB) बड़ी फाइलों का सपोर्ट:**
   - यूज़र किसी भी डायरेक्ट लिंक (`https://.../app.ipa`) से 2GB, 3GB, 5GB या उससे भी बड़ी IPA फाइल भेज सकते हैं।
   - बॉट में बिल्ट-इन हाई-स्पीड वेब सर्वर (पोर्ट `8080`) जोड़ा गया है, जिससे साइन होने के बाद 2GB+ बड़ी फाइलों का डायरेक्ट डाउनलोड लिंक मिल जाता है।

3. **👑 एडमिन डैशबोर्ड (@YQIS):**
   - एडमिन कंट्रोल केवल **@YQIS** के पास है।
   - डैशबोर्ड फीचर्स:
     - 📊 कुल रजिस्टर्ड यूज़र्स और साइनिंग आंकड़े।
     - 👥 यूज़र लिस्ट व एक्टिविटी।
     - 🧹 सर्वर स्टोरेज क्लीनर (पुरानी टेम्प फाइल्स हटाना)।
     - 📢 सभी यूज़र्स को एक साथ ब्रॉडकास्ट मैसेज भेजना।
   - कमांड: `/admin` या कीबोर्ड से `👑 Admin Dashboard`।

4. **🔒 पूर्ण गोपनीयता (No Username Leaks):**
   - IPA साइन होने पर किसी का भी यूज़रनेम (ना तो एडमिन @YQIS का, ना ही किसी अन्य का) दिखाई नहीं देता है।
   - बॉट के सभी मैसेजेस बिल्कुल क्लीन, न्यूट्रल और प्रोफेशनल हैं।

---

## ⚙️ एडमिन कमांड्स (Admin Commands)
- `/admin` - एडमिन कंट्रोल पैनल खोलें (केवल `@YQIS` के लिए)।
